말하는 속도

이 언어의 목소리가 이 기기에 없어요. 기기 설정에서 음성을 추가해 주세요.

더 사람 같은 목소리 받는 방법

iPhone·iPad: 설정 → 손쉬운 사용 → 말하기 콘텐츠 → 목소리에서 프리미엄·향상된 목소리를 내려받아요.

Android: 설정의 텍스트 음성 변환(TTS)에서 Google 음성 데이터를 설치해요.

Windows: Edge 브라우저에서 이름에 Natural이 붙은 목소리를 골라요.

Mac: 시스템 설정 → 손쉬운 사용 → 말하기 콘텐츠 → 시스템 음성 → 음성 관리에서 프리미엄 음성을 받아요.

내려받은 뒤 이 화면을 새로고침하면 목소리 목록에 나타나요.
